# ORGANIZADOR_DE_ARQUIVOS
Automação em python com interface grafica que realiza uma organização de arquivos por extensão em pastas determinadas pelo usuário.

# Como usar?
 - CRIANDO AS PASTAS
   Insira o nome das pasta que deseja criar.
   Caso queira apenas um ou alguns tipos de arquivos, deixe os que não irá utilizar em branco.
   Mostre onde estão os arquivos digitando o caminho ou utilizando o botão "BROWSE", selecione o local dos arquivos,depois clique em "Ok"
   Clique em "ORGANIZAR" e pronto.
- USANDO PASTAS JÁ CRIADAS
   Insira o nome das pastas que ja foram criadas.
   Mostre onde estão os arquivos digitando o caminho ou utilizando o botão "BROWSE", selecione o local dos arquivos,depois clique em "Ok"
   Clique em "ORGANIZAR" e pronto.
